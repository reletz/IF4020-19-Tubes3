    Nadina.Profile behaviour (Nadina v0.1.0)

    Copy Markdown View Source

    Behaviour untuk profil algoritma tanda tangan (Tabel 2.1 spesifikasi).

    Setiap profil (rsa-pss-sha256, ecdsa-p256-sha256, ed25519) mengimplementasikan behaviour ini. Hanya modul Nadina.Profile dan Nadina.Keys yang menyentuh API kripto OTP. Modul lain memakai profil lewat behaviour ini.

    Kunci direpresentasikan sebagai record dari pustaka public_key OTP, hasil pem_entry_decode atau generate_key.

    • kunci privat berupa record RSAPrivateKey atau ECPrivateKey
    • kunci publik berupa record RSAPublicKey atau tuple {{ECPoint, titik}, parameter}

    Aturan umum untuk semua implementasi

    • sign menerima byte manifest M apa adanya. SHA-256 diterapkan tepat satu kali (RSA-PSS dan ECDSA), sedangkan Ed25519 menerima M tanpa hashing eksternal.
    • verify tidak boleh raise. Tanda tangan dengan panjang atau nilai yang tidak sah menghasilkan false.

    key_error()

    Alasan kunci ditolak oleh check_key.

    name()

    Nama profil, dipakai sebagai nilai algorithm pada manifest.

    private_key()

    Record kunci privat dari pustaka public_key.

    public_key()

    Record kunci publik dari pustaka public_key.

    Callbacks

    check_key(arg1)

    Memeriksa bahwa kunci (privat atau publik) sesuai tipe dan parameter profil.

    generate_key()

    Membangkitkan pasangan kunci baru dari CSPRNG.

    name()

    Nama profil sesuai Tabel 2.1, misalnya ed25519.

    public_from_private(private_key)

    Menurunkan kunci publik dari kunci privat.

    sign(private_key, message)

    Menandatangani byte message dengan kunci privat. Mengembalikan tanda tangan mentah sepanjang signature_size byte.

    signature_size()

    Panjang tanda tangan dalam byte sebelum Base64 (384, 64, atau 64).

    verify(public_key, message, signature)

    Memverifikasi signature atas message. Tidak pernah raise. Nilai yang tidak sah menghasilkan false.

    Callbacks

    check_key(arg1)

    @callback check_key(private_key() | public_key()) :: :ok | {:error, key_error()}

    Memeriksa bahwa kunci (privat atau publik) sesuai tipe dan parameter profil.

    Hasilnya ok bila sesuai, error wrong_key_type bila tipe kunci salah, atau error wrong_parameters bila parameter (ukuran modulus, eksponen, kurva) salah.

    generate_key()

    @callback generate_key() :: {private_key(), public_key()}

    Membangkitkan pasangan kunci baru dari CSPRNG.

    name()

    @callback name() :: name()

    Nama profil sesuai Tabel 2.1, misalnya ed25519.

    public_from_private(private_key)

    @callback public_from_private(private_key()) :: public_key()

    Menurunkan kunci publik dari kunci privat.

    sign(private_key, message)

    @callback sign(private_key(), message :: binary()) :: binary()

    Menandatangani byte message dengan kunci privat. Mengembalikan tanda tangan mentah sepanjang signature_size byte.

    signature_size()

    @callback signature_size() :: pos_integer()

    Panjang tanda tangan dalam byte sebelum Base64 (384, 64, atau 64).

    verify(public_key, message, signature)

    @callback verify(public_key(), message :: binary(), signature :: binary()) :: boolean()

    Memverifikasi signature atas message. Tidak pernah raise. Nilai yang tidak sah menghasilkan false.

    Functions

    fetch(name)

    @spec fetch(String.t()) :: {:ok, module()} | :error

    Mencari modul profil dari nama. Nama tidak dikenal menghasilkan error.

    Contoh

    iex> Nadina.Profile.fetch("ed25519")
{:ok, Nadina.Profile.Ed25519}

iex> Nadina.Profile.fetch("rsa-sha1")
:error
