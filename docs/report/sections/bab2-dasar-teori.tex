\subsection{Software Bill of Materials (SBOM)}
SBOM adalah daftar komponen yang menyusun sebuah perangkat lunak, beserta versi dan
\textit{checksum}-nya. Daftar ini membantu pengguna memeriksa dependensi yang masuk ke sebuah
rilis. Format SBOM beragam, misalnya CycloneDX dan SPDX. Setiap komponen biasanya dinyatakan
dengan \textit{package URL} (purl), yaitu skema penamaan paket yang berbentuk
\texttt{pkg:<tipe>/<nama>@<versi>}.

SBOM dapat ikut ditandatangani agar isinya tidak diubah setelah dibuat. Dengan menyimpan
SHA-256 artefak di dalam SBOM, pemeriksa juga dapat memastikan bahwa SBOM memang merujuk
artefak yang sedang diperiksa. Contoh keluaran kakas eksternal dapat dilihat pada Kode~\ref{lst:sbom}.

\begin{lstlisting}[basicstyle=\ttfamily\footnotesize,caption={Potongan SBOM CycloneDX yang dihasilkan Trivy},label={lst:sbom},numbers=none]
{
  "bomFormat": "CycloneDX",
  "specVersion": "1.7",
  "components": [
    {
      "bom-ref": "pkg:npm/lodash@4.17.21",
      "type": "library",
      "name": "lodash",
      "version": "4.17.21",
      "licenses": [{"license": {"id": "MIT"}}],
      "purl": "pkg:npm/lodash@4.17.21"
    }
  ]
}
\end{lstlisting}
